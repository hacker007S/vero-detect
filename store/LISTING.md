## Description
Selling on eBay? One VeRO complaint can end your account.

VeRO Detect checks the product you are viewing — on eBay, Amazon or
AliExpress — against eBay's VeRO (Verified Rights Owner) programme and UK
restricted-item rules, instantly, before you list it.

WHAT IT CHECKS
✔ 1,100+ VeRO-enrolled brands (auto-updated weekly)
✔ Brand & trademark mentions, including common misspellings
✔ UK prohibited & restricted items (7 categories)
✔ Sensitive classes: skincare claims, toys/UKCA, batteries, food
✔ Size & weight flags for postage planning
✔ Optional AI deep check using your own free Gemini API key

HOW IT WORKS
Open any product page → the VeRO Detect badge appears → one click gives you
a clear verdict: 🟢 clear · 🟡 caution · 🔴 danger, with the exact reason and
what to do about it.

100% FREE · NO ACCOUNT · NO DATA COLLECTED
Everything runs inside your browser. No server, no tracking, no sign-up.

## Permission justifications
- storage — saves the user's settings (e.g. optional AI API key) and the
  cached rules pack locally.
- alarms — schedules the weekly refresh of the public rules data file.
- host: ebay.co.uk / ebayimg / aliexpress / amazon / alicdn / media-amazon —
  the product pages and their images that the extension reads locally to
  perform its checks.
- host: raw.githubusercontent.com — downloads the public rules DATA file
  (JSON only; no executable code is ever fetched or evaluated).
- host: generativelanguage.googleapis.com, api.openai.com, api.anthropic.com
  — used ONLY when the user saves their own API key and manually clicks
  "Deep check"; the listing text is sent to the provider the user chose.
